A C++ program that simulates a free library system by managing and sorting a collection of books using multiple sorting algorithms.

🚀 Features
Imports book data from a tab-separated file
Stores books using a vector of Book objects
Extracts author first and last names from a single string
Implements multiple sorting algorithms:
Quicksort → Sort by title
Merge Sort → Sort by author's last name
Insertion Sort → Sort by last name in reverse order
Menu-driven interface for user interaction
Exception handling using try-throw-catch during file import
